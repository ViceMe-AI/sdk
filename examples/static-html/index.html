ViceMe SDK — static HTML

Style 1 — declarative auto-mount. The loader reads data-viceme-* attributes, loads the same-version core and feature chunks from the release manifest, and mounts into the target.

Style 2 — browser-native ESM with explicit lifecycle control (paste into a <script type="module">): 

import { createViceMe } from 'https://cdn.viceme.cn/sdk/1.0.0/index.js';

const client = createViceMe({ workKey: 'wrk_public_example', region: 'cn' });
await client.ready();

window.addEventListener('pagehide', () => client.destroy());
